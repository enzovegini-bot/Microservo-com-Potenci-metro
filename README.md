# Microservo-com-Potenci-metro

aluno : Enzo Hebling Vegini

descrição : Resumo da atividade

Nesta atividade, foi utilizado o Arduino no Tinkercad para integrar um potenciômetro e um microservo. O potenciômetro funciona como dispositivo de entrada, enviando valores ao Arduino, que utiliza essas informações para controlar a posição do microservo. A prática demonstra a integração entre entrada, programação e saída em um sistema de controle aplicado à IoT.
